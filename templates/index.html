¿Cómo usar?

1. Obtén tus credenciales

Ve a la consola de Huawei Cloud → IAM → Mis credenciales → Claves de acceso. Crea o copia tu Access Key (AK) y Secret Key (SK).

2. Ingresa los datos

Pega tu AK, SK y Project ID en el formulario. Selecciona la región donde están tus recursos.

3. Elige el servicio

Puedes consultar un servicio específico (ECS, EVS, VPC, etc.) o todos a la vez con "Todos los servicios".

4. Consulta y exporta

Pulsa Consultar. Usa el buscador y filtros para encontrar recursos. Pulsa Exportar Excel para descargar los resultados.

Nota: Las credenciales se envían solo a Huawei Cloud durante la consulta y nunca se guardan en el navegador ni en el servidor.
